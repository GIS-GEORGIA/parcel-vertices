# parcel-vertices

საკადასტრო კოდით ნაკვეთის ძებნა → წვეროების კოორდინატების ცხრილი (WGS84 / UTM 37N, 38N) → CSV / DXF ექსპორტი GPS-ისა და ტაქეომეტრისთვის.
Flutter (Android · Web · Windows). API: maps.gov.ge (იგივე, რაც `georgian_cadastre` QGIS პლაგინში).

```
flutter pub get
flutter run -d windows   # ან android
flutter test
```

შენიშვნა: Web-ზე maps.gov.ge-ს CORS-ის გამო შეიძლება პროქსი დაჭირდეს.
